# 去 AI 味审稿助手｜Prose Naturalness Review

基于 checklist 的中文审稿 Skill：定位模板化表达，解释问题，提供修改建议，保留作者的写作口吻。

## 可以做什么

- 检查重复解释、空泛表达、机械动作、对白失真、人物口吻和叙事衔接。
- 根据上下文区分明确问题、可选优化和材料不足。
- 提供有原文依据的修改建议、局部改写和修改后复查。
- 支持中文小说及普通文章；跳过不适用的检查项。

它检查文字质量，不鉴定作者身份，不计算 AI 生成概率，也不保证发现所有问题或通过检测器。句式、比喻和停顿都不是一律禁止的对象。

## 安装到 Codex

下载仓库，将包含 `SKILL.md` 的整个目录放到 `~/.codex/skills/prose-naturalness-review/`，重新打开会话后使用。

该技能由 Markdown 指令和参考文件组成，无需 API Key 或额外运行依赖。其他支持 Skills 的工具可按各自的技能安装方式加载。

## 使用示例

```text
用 $prose-naturalness-review 检查下面这段文章。
先给原文，再按点说明问题和改法，最后提供修改后的内容。
保留人物口吻，不补写新的情节。

[粘贴正文]
```

也可以要求“只审阅，不改正文”“只轻度润色”或“对照上一版问题复查”。未明确授权时，审阅模式不会直接改写正文文件。

## 文件结构

- `SKILL.md`：任务范围、执行流程和判定边界。
- `references/checklist.md`：详细检查清单。
- `references/examples.md`：六组校准教学例子。
- `references/reporting.md`：证据与输出格式。
- `references/project-and-sources.md`：项目规则适用边界。
- `agents/openai.yaml`：Codex 展示信息。
